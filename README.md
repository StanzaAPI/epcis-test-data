# EPCIS Test Data

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23076200.svg)](https://doi.org/10.5281/zenodo.23076200)

ObjectEvent records in EPCIS 2.0 JSON-LD for track-and-trace tests, with synthetic SGTIN EPCs.

Free to use under **CC0-1.0** (public domain dedication, no attribution required).

DOI: [10.5281/zenodo.23076200](https://doi.org/10.5281/zenodo.23076200)

## Files

- `epcis-small.json`
- `epcis-small.csv`
- `epcis-medium.json`
- `epcis-medium.csv`
- `epcis-large.json`
- `epcis-large.csv`

Each size ships as JSON and CSV. The data is deterministic: the same size always
produces the same rows.
